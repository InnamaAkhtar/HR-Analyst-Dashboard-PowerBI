# HR Analyst Dashboard – Power BI

## 📊 Project Overview
The **HR Analyst Dashboard** is an interactive Power BI dashboard designed to analyze employee data and provide meaningful insights into workforce demographics, salary distribution, department-wise employee count, work modes, yearly trends, and employee locations.

This dashboard helps HR teams monitor key workforce metrics and make data-driven decisions.

## 🎯 Key Performance Indicators (KPIs)

- **Total Employees:** 1,000
- **Average Salary:** 596,088
- **Average Age:** 38.27 years
- **Total Departments:** 8

## 📈 Dashboard Visualizations

The dashboard includes the following charts:

- **Gender Distribution:** Analyzes employees by gender.
- **Total Employees by Department:** Shows employee distribution across departments.
- **Total Employees by Work Mode:** Compares employees based on work mode.
- **Total Employees by Year:** Displays yearly employee trends.
- **Total Employees by Location:** Analyzes employee distribution across different locations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- HR Data Analysis
- KPI Reporting
- Interactive Dashboard Design

## 💡 Key Objectives

- Monitor overall workforce metrics.
- Analyze employee demographics and department distribution.
- Understand work mode and location-based workforce patterns.
- Track employee trends across years.
- Support data-driven HR decision-making.
